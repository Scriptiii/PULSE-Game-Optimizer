# PULSE — Game Optimizer

<img src="pulse/assets/pulse.png" width="64" alt="Логотип PULSE">

Приложение на Python для настройки Windows под игры с графическим интерфейсом на PySide6. Тёмная тема, фирменная оранжевая молния и локальный мониторинг системы.

**Версия 1.10.0.** Независимый проект, вдохновлённый интерфейсом Hone; не связан с Hone или Microsoft.

## Возможности

| Раздел | Возможности |
| --- | --- |
| Обзор | Нагрузка CPU, использование ОЗУ и диска, конфигурация ПК, ручная очистка ОЗУ |
| Оптимизации | 56 настроек в 7 секциях, поиск, выбор раздела, применение с подтверждением и откат |
| Очистка | Временные файлы, необязательные компоненты Windows, удаление EXE / MSI, размеры программ и сортировка |
| Автозагрузка | Поддерживаемые приложения и службы Windows с переключателями запуска |
| Восстановление | Возврат исходных значений настроек и автозагрузки из сохранённых копий |

Результат оптимизаций зависит от оборудования, игры и настроек Windows. Увеличение FPS не гарантируется.

## Требования

- Windows 10 1809 или новее / Windows 11, x64.
- Python 3.10–3.14 x64 с pip.
- Интернет для первоначальной установки зависимостей.

Для системных настроек, очистки ОЗУ и удаления системных установок нужны права администратора. Недоступные действия объясняются в интерфейсе.

## Запуск

Скачайте исходники, откройте папку проекта и запустите **`run.bat`**. Скрипт создаст локальное окружение `.venv`, установит зависимости и откроет PULSE.

Для запуска вручную выполните в PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

При запуске `main.py` из редактора выберите интерпретатор `.venv\Scripts\python.exe`.

**`demo.bat`** запускает демонстрационный режим. Настройки, автозагрузка и удаление приложений работают с вымышленными данными в памяти; очистка файлов и реальной ОЗУ отключена. Мониторинг показывает нагрузку текущего компьютера.

Открытие приложения само по себе не применяет твики. Настройки выбираются вручную и применяются после подтверждения.

## Работа с приложением

### Настройки и восстановление

Плитки сгруппированы по секциям: питание, игровые функции, фоновые функции Windows, Edge, Проводник, внешний вид, мышь и клавиатура. Можно выбрать отдельные пункты или целый раздел. Уже применённые и недоступные пункты пропускаются.

Перед изменением сохраняются исходные значения. Раздел **«Восстановление»** позволяет отменить изменение отдельного параметра или сохранённого набора. Доступность зависит от версии и редакции Windows, оборудования и политик системы.

### Очистка ОЗУ

На главной странице под индикатором памяти находится кнопка **«Очистить ОЗУ»**. По нажатию в фоне очищаются рабочие наборы процессов, системный файловый кеш и Standby. Для операции нужны права администратора.

Результат показывает доступную память до и после и статус каждой операции. Память может снова использоваться приложениями при обращении к данным; прирост доступной ОЗУ не гарантируется. Автоматическая очистка не включается.

### Очистка файлов и приложений

- Временные файлы удаляются только из поддерживаемых папок Temp и только старше 48 часов. Список показывается после анализа, удаление требует подтверждения и выполняется без корзины.
- Загрузки, документы, кеш браузеров и шейдеров не входят в очистку временных файлов. Ссылки и занятые файлы пропускаются.
- Необязательные компоненты Windows удаляются штатными средствами после выбора и подтверждения. Назначение каждого пункта указано в интерфейсе.
- Программы EXE / MSI ищутся по регистрации установок в реестре. Portable-программы без регистрации могут отсутствовать.
- Размер берётся из данных установщика и может отличаться от фактического размера на диске. Если он неизвестен, показывается «—». Доступна сортировка по названию и размеру в обе стороны.
- Для EXE / MSI открывается штатный мастер удаления. Затем проверяются завершение процесса, регистрация установки и зарегистрированная папка программы. Остатки и неполная проверка отображаются в отчёте.

Размер программы не является обещанием освободить такой же объём. Данные вне проверенной папки установки и общие файлы не стираются по догадке. Удалённые приложения и файлы не восстанавливаются через копии настроек PULSE.

Списки в **«Очистке»** и **«Автозагрузке»** загружаются при первом открытии за запуск программы. Повторный вход использует сохранённые данные. Кнопка **«Обновить»** запускает повторный поиск; после изменения автозапуска или удаления список обновляется с учётом результата.

### Автозагрузка

Переключатели управляют запуском поддерживаемых приложений и служб при следующем входе или загрузке Windows. Для служб показывается подтверждение. Исходная конфигурация сохраняется для восстановления. Работающие процессы и службы при переключении не останавливаются; защищённые записи доступны только для просмотра.

## Данные приложения

Настройки восстановления, журналы и отчёты хранятся вне папки проекта:

```text
%LOCALAPPDATA%\PulseOptimizer\
```

Копии параметров находятся в `backups`, изменения автозагрузки — в `startup`, отчёты удаления — в `uninstall`.

Копии PULSE сохраняют настройки, а не файлы пользователя или удалённые приложения. Откат заменяет и более поздние ручные изменения тех же параметров Windows.

## Сборка EXE

Запустите **`build.bat`**. Скрипт установит зависимости и PyInstaller, затем создаст:

```text
dist\PULSE\PULSE.exe
```

Переносите **всю папку `dist\PULSE`**, включая `_internal`. В EXE встроена фирменная иконка. Готовые сборки и локальное окружение исключены из Git через `.gitignore`.

## Структура

```text
main.py             запуск приложения

requirements.txt    зависимости для запуска
run.bat             запуск и установка зависимостей

```

## Используемые технологии и источники

- [Qt for Python / PySide6](https://doc.qt.io/qtforpython-6/) — интерфейс.
- [psutil](https://github.com/giampaolo/psutil) — мониторинг системы.
- [Рекомендации Microsoft по производительности Windows](https://support.microsoft.com/en-us/windows/experience/performance-optimization/tips-to-improve-pc-performance-in-windows).
- [Windows Installer: данные установленной программы](https://learn.microsoft.com/en-us/windows/win32/msi/uninstall-registry-key) — регистрация и размеры EXE / MSI.
- [WinMemoryCleaner 3.0.8](https://github.com/IgorMundstein/WinMemoryCleaner/tree/3.0.8) — ориентир для выбора операций очистки ОЗУ; реализация PULSE написана на Python и не требует стороннего EXE.

Во время обычной работы PULSE не отправляет телеметрию. Внешние ссылки открываются по нажатию пользователя.
